# AI 配图提示词参考

本文档用于排版 `.pptx` 和网页演示路线中的 AI 配图。这里的图片是嵌入页面的视觉素材，不是完整幻灯片。纯图片 PPT 的整页 prompt 使用 `references/image-pptx/styles/`。

## 通用规则

- 先确定图片槽位和比例，再写 prompt。不要先生成图片再硬塞进页面。
- 配图默认不承担关键文字、精确数字、logo、水印、页眉、页脚、页码、标题栏或 PPT 外壳。
- 生图服务返回的图片默认带有**合规水印**（平台强制要求）。prompt 中的「不要水印」指画面内容内不要自绘角标/伪 logo，**不是**要求去除该服务水印；校验与 QA 时不得因此判 FAIL，详见 `references/shared/image-gen.md` 的「合规水印（生图服务默认）」。
- 标题、正文、准确数据、品牌名称和法务文本必须由 PPT/HTML 原生文本承担。
- 图片要为原生文字预留可叠加空间，画面密度中等，不要满屏堆细节。
- 同一页或同一组图片必须保持相同画风、比例、视觉缩放、边距密度和线条粗细。
- 真实照片尽量不要带文字；信息图内部如必须有标签，只允许短标签。
- 生成前先估算图片张数；若生图服务返回额度或可用性限制，再减少图片数或走降级方案。

## 路线风格锚点

### 排版 `.pptx`

风格跟随 `references/shared/design-system.md` 中选定的设计体系和主题色。常见对应关系：

| PPT 风格 | 配图锚点 |
|----------|----------|
| 商务简约 | 干净留白、低饱和商务摄影、蓝灰色系、克制图形 |
| 科技专业 | 深色或冷白背景、细线系统图、抽象科技纹理、蓝紫强调 |
| 正式庄重 | 稳定对称构图、深蓝/深红/金色点缀、低装饰 |
| 温润亲和 | 自然光、人文现场、柔和暖色、轻插画 |
| 高端品牌 | 大留白、精致材质、极简主视觉、弱文字 |
| 中国风 | 水墨纹理、新中式色彩、宣纸质感、留白构图 |

### 网页演示 · 典雅画报风

电子杂志、电子墨水、人文纪实、衬线标题气质。配图应克制、真实、留白充足，避免霓虹科技感、SaaS 模板感和假 logo。

### 网页演示 · 简约商务风

Swiss International Typographic Style、Helvetica/Inter 气质、12/16 列网格、直角模块、发丝线和单一高饱和 accent。避免渐变、阴影、圆角、玻璃拟态、3D、卡通和装饰边框。

### 网页演示 · AI 配图规划规则

- **先布局后配图**：配图规划必须在布局选型完成后执行，只能为有图片槽位的页面生成配图。无槽位的页面不列入配图计划；HTML 路线的封面始终无槽位。
- **HTML 路线封面不生成配图**：风格 A 和风格 B 的封面均无图片槽位（WebGL 流体 / IKB+ASCII 即主视觉），配图计划不应列入封面。PptxGenJS 路线不设封面配图规则，由 agent 按内容自行安排。
- **按内容需要选槽位**：从有图片槽位的布局中，根据页面内容判断哪个位最需要视觉支撑（如故事页需要场景图、产品页需要产品照），而非机械按页序分配。
- **配图清单字段**：页码、布局编号、图片槽位类型、用途、图片类型、目标比例、实际 size、输出路径、HTML 槽位 class、预计生成张数。

## 比例与尺寸

推荐尺寸和完整比例对照见 `references/shared/image-gen.md`。下表只列用途与比例对应关系：

| 用途 / 槽位 | 推荐比例 | 说明 |
|-------------|----------|------|
| 全屏主视觉 / 封面背景 | 16:9 | 预留标题区，不放关键小字 |
| S22 顶部主图 / 超宽横幅 | 21:9 | 核心主体放中央安全区 |
| 左文右图主图 | 4:3 / 3:2 | 根据槽位接近度选择 |
| 多图格 / 证据组 | 16:9 / 4:3 / 21:9 | 同组必须统一比例 |
| UI / 截图再设计 | 3:2 / 21:9 | 文字密集时优先 fit-contain |
| 图标 / 小装饰 | 1:1 | 生成后缩小使用 |
| 背景纹理 | 16:9 / 21:9 | 低对比，不能抢正文 |

## Prompt 后缀

每个配图 prompt 最后补充一段规格约束：

```text
输出必须是[比例]构图，主体清晰但保留足够边距，画面密度中等，与同组图片保持相同视觉缩放、边距和线条粗细。只保留核心图像本身，不要生成页眉、页脚、标题栏、页码、角标、署名、logo、水印、装饰边框、PPT 外壳、超长条、竖图或不规则比例。
```

同一组图片中的每一张再补充：

```text
这是一组图片中的一张，请保持与同组图片相同的画面比例、元素大小、边距、线条粗细、标注密度和色彩系统。
```

## 图片类型

### `photo-documentary`

用于真实场景、人物、行业现场和氛围锚点。

```text
生成一张[比例]纪实摄影配图，主题是：[页面概念]。风格真实、克制、低饱和、自然光，有人文温度，适合[排版 PPT/网页演示]的视觉系统。主体位于安全区内，并为标题或正文保留留白。不要商业摆拍、AI 机器人、科幻界面、logo、水印或文字。
```

### `editorial-illustration`

用于杂志感概念解释、叙事配图和轻量插画。

```text
生成一张[比例]杂志编辑风插画，表达：[概念/故事/主题]。构图有明显主视觉和留白，色彩跟随当前 deck 的主题色，细节克制，有现代编辑设计感。不要卡通低幼、3D 玩具感、霓虹科技感、SaaS 模板感、logo、水印或长文字。
```

### `concept-visual`

用于封面、章节页和抽象战略主题。

```text
生成一张[比例]抽象概念主视觉，主题是：[战略主题/核心概念]。画面需要有强视觉锚点、充足负空间、清晰明暗层次，并与当前 deck 的色彩和气质一致。不要生成标题、标语、logo、水印或 PPT 页面边框。
```

### `process-diagram`

用于流程、路线图、pipeline 和阶段关系。仅用于非精确表达，正式文字标签应在 PPT/HTML 原生层实现。

```text
生成一张[比例]流程关系视觉，表达：[步骤 1] 到 [步骤 2] 到 [步骤 3] 到 [结果] 的过程。使用简洁节点、箭头、分段结构和少量无语义短标签，占位感即可。不要生成长文字、精确数字、页眉、页脚、标题或装饰边框。
```

### `comparison-visual`

用于 before/after、新旧模式、两种路径对比。

```text
生成一张[比例]左右对比视觉，左侧表达：[旧模式]，右侧表达：[新模式]。两侧结构平衡，视觉差异清楚，使用当前 deck 的主题色作为唯一强调色。不要生成可读长文字、精确数字、logo、水印或页面标题。
```

### `system-relationship`

用于多角色、多模块、多工具之间的关系。

```text
生成一张[比例]系统关系视觉，展示：[角色/模块/工具]之间的连接关系。使用清晰节点、细线、分层结构和适度留白，整体与当前 deck 的设计体系一致。内部只允许极短占位标签，不要生成长文字、真实 logo、页眉、页脚或装饰边框。
```

### `ui-redesign`

用于把截图、代码、dashboard 或工作区重绘为统一视觉素材。

```text
生成一张[比例]UI 情景图，将[截图/界面/工作区内容]再设计成适合当前 deck 的统一视觉素材。保留真实产品工作流的感觉，使用干净面板、网格、少量短标签和清晰层级。不要使用真实品牌 logo，不要生成花哨 dashboard、霓虹渐变、过度拟物或长文字。
```

### `data-infographic`

用于非精确数据氛围图、指标视觉和数据主题页的配图。准确数字必须放在原生文本层。

```text
生成一张[比例]数据氛围信息图，主题是：[指标含义/数据趋势]。使用抽象柱形、折线、模块化色块、放大数字轮廓或几何图形表达数据感，但不要生成需要准确读取的数字或表格。整体清晰、克制、留白充足。
```

### `icon-flat`

用于列表页、特性页和能力模块的小图标。

```text
生成一个 1:1 简洁扁平图标，概念是：[图标含义]。使用当前 deck 的主题色和中性色，线条清晰，背景透明或纯色，适合缩小到 PPT/HTML 中作为小图标。不要文字、logo、水印、复杂场景或照片质感。
```

### `texture-background`

用于背景纹理、抽象渐变、纸张质感或轻装饰氛围。

```text
生成一张[比例]低对比背景纹理，视觉关键词是：[纹理/材质/氛围]。整体必须安静、均匀、低细节，为标题和正文留出充足可读空间。不要生成文字、图标、logo、水印、边框或强主体。
```

## 命名与落盘

`.pptx` 路线：

```text
{工作目录}/.temp/images/{页号}-{语义}.png
```

HTML 路线：

```text
{交付目录}/images/{页号}-{语义}.png
```

文件名使用英文短语和补零页号，例如 `01-cover-hero.png`、`03-process-map.png`、`07-feature-icon.png`。
