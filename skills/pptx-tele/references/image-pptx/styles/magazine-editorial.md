# 杂志编辑

## 风格 ID

magazine-editorial

## 适用场景

行业观察、文化传播、人物故事、趋势分享、品牌叙事。

## 基础提示词模板

你是一位资深杂志美术指导，请生成一张 16:9 横向完整幻灯片图片。整体像高端独立杂志跨页：人文纪实、故事感、自然光、低饱和暖色、胶片颗粒、纸张纹理和优雅留白。标题具有编辑排版气质，可使用衬线标题与无衬线正文的对比。不要卡通、霓虹科技感、SaaS 模板感、廉价图库感、伪 logo 或水印。

## 页面类型模板

### 封面页 (cover)

使用大幅纪实主视觉或抽象纸张纹理作为背景。主标题像杂志封面标题，位于左上、居中或跨越画面一侧。副标题较小，保持编辑感和呼吸感。

### 内容页 (content)

采用杂志分栏或图文混排。标题区清晰，正文要点像编辑注释、拉引或短栏。可加入少量手写感标注、细线、编号，但不要过度装饰。

### 数据页 (data)

使用杂志信息图风格：低饱和色块、细线图表、大数字、短注释。图表只表达趋势和氛围，不承担复杂精确数据。

### 总结页 (closing)

使用留白和一句强总结形成收束。可放一张安静的纪实照片、纸张纹理或低饱和背景，让行动号召区域清晰可读。
