# 极简海报

## 风格 ID

minimal-poster

## 适用场景

发布会金句、品牌宣言、创意提案、轻量观点表达、一次性视觉演示。

## 基础提示词模板

你是一位极简海报和平面设计专家，请生成一张 16:9 横向完整幻灯片图片。整体风格为大面积留白、特大字排版、单一强调色块、强网格、极少装饰。画面像现代品牌海报或发布会大屏，克制、直接、清晰。不要复杂背景、照片堆叠、3D、渐变炫技、伪 logo、水印或多余文字。

## 页面类型模板

### 封面页 (cover)

主标题占据画面视觉中心或左侧大面积区域，副标题很小，强调强烈字号对比。可使用一个单色几何形状或极简符号作为视觉锚点。

### 内容页 (content)

每页只表达一个核心观点，配 1-3 个极短要点。使用大标题、细线、编号或单色色块组织层级，保留大量空白。

### 数据页 (data)

用一个超大数字或一个极简图形表达数据感。不要生成复杂图表或精确表格；只保留关键指标的视觉冲击。

### 总结页 (closing)

使用一句短行动号召或总结句作为主体。画面极简、干净，底部或角落可预留小号补充信息。
