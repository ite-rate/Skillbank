# 数据可视化

## 风格 ID

data-viz

## 适用场景

数据汇报、市场分析、KPI 总结、趋势洞察、业务复盘。

## 基础提示词模板

你是一位数据可视化和信息图设计专家，请生成一张 16:9 横向完整幻灯片图片。整体风格为信息图、几何化图表、色块分区、大数字、清晰注释和强信息层级。画面要像高质量数据报告封面或数据大字报，但必须避免生成复杂精确表格、过多小字、乱码、伪 logo 或水印。

## 页面类型模板

### 封面页 (cover)

使用数据网格、抽象图表、地图轮廓或指标模块作为主视觉。主标题清晰，数据元素作为背景和氛围，不喧宾夺主。

### 内容页 (content)

使用 2-3 个指标卡片、结论模块或趋势摘要区。每个模块有醒目的数字或图形，但文字保持短小。

### 数据页 (data)

使用大数字、简化柱状图、折线趋势、矩阵、漏斗或环形图表达数据故事。只展示少量关键数值，不生成复杂表格。准确数据仍应在排版 PPT 路线中用原生图表完成。

### 总结页 (closing)

将关键指标和结论收束为一个清晰视觉。可使用一个大数字、趋势箭头或结果卡片作为中心，留出行动建议区域。
