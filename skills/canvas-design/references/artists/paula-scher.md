# Paula Scher (1948-)
## "Typographic Maximalism"

**Characteristics:**
- Typography as primary visual
- Layered text compositions
- Vibrant colors
- Information density
- Expressive letterforms
- Grid-breaking layouts

**Prompt Modifiers:**
```
Paula Scher style poster, typography as primary visual element, layered text
composition, vibrant color palette, dense information design, expressive
hand-drawn letterforms, grid-breaking dynamic layout, contemporary typographic
maximalism
```

**Best For:** Music events, festivals, text-heavy subjects
