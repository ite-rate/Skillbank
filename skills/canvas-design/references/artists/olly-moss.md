# Olly Moss (1987-)
## "Contemporary Minimalism Master"

**Characteristics:**
- Ultra-minimal compositions
- Clever negative space
- Visual double meanings
- 1-3 color palettes
- Iconic objects over faces
- Figure-ground inversion
- Saul Bass influence

**Prompt Modifiers:**
```
Olly Moss style Mondo poster, ultra minimalist design, clever negative space,
hidden imagery within silhouette, 2-color limited palette, geometric simplicity,
visual double meaning, symbolic object-focused, Saul Bass influence, contemporary
Mondo aesthetic
```

**Best For:** Films with iconic imagery, conceptual themes, noir
