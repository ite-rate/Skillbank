# 每日AI知识点题库

## 选取规则

- 每次生成日报时从中选取1-2个知识点
- 第1个：从"热门概念池"中按日期轮换选取（用当天日期对池长度取模，保证每天不同）
- 第2个（可选）：与当天新闻主题相关的知识点，从"进阶概念池"选取
- 知识点需用通俗语言撰写，避免学术黑话，让非技术人员也能看懂

## 热门概念池（基础，25个）

1. **RAG（检索增强生成）** - 让大模型先"查资料"再回答，减少幻觉。场景：企业知识库问答。`[标签: NLP]`
2. **AI Agent（智能体）** - 能自主规划步骤、调用工具完成任务的AI。场景：自动处理邮件和日程。`[标签: Agent]`
3. **Fine-tuning（微调）** - 在通用模型基础上用特定数据继续训练。场景：训练行业专属模型。`[标签: 训练]`
4. **Prompt Engineering（提示词工程）** - 通过优化输入指令来提升AI输出质量。场景：让AI写更精准的文案。`[标签: NLP]`
5. **MoE（混合专家模型）** - 把大模型拆成多个"小专家"，每次只激活相关专家，省算力。场景：低成本部署超大模型。`[标签: 架构]`
6. **Embedding（向量嵌入）** - 把文本变成数字向量，让AI理解语义相似度。场景：相似文档搜索。`[标签: NLP]`
7. **Token** - AI处理文本的最小单位，约等于0.75个中文字。场景：理解API计费单位。`[标签: 基础]`
8. **RLHF（人类反馈强化学习）** - 用人类打分来训练AI，让它回答更符合人类偏好。场景：让AI更礼貌有用。`[标签: 训练]`
9. **Hallucination（幻觉）** - AI自信地编造不存在的事实。场景：识别AI回答中的虚假信息。`[标签: 安全]`
10. **LoRA（低秩适配）** - 用极少量参数微调大模型，成本低效果好。场景：个人电脑微调大模型。`[标签: 训练]`
11. **Transformer** - 目前几乎所有大模型的底层架构，用注意力机制理解上下文。场景：理解GPT/Claude的底层原理。`[标签: 架构]`
12. **Context Window（上下文窗口）** - 模型一次能"记住"的文本长度上限。场景：判断能否一次性处理长文档。`[标签: 基础]`
13. **Inference（推理）** - 模型训练好后，根据输入生成输出的过程。场景：理解"推理成本"vs"训练成本"。`[标签: 基础]`
14. **Multimodal（多模态）** - AI同时理解文字、图片、音频等多种输入。场景：让AI看图说话、看视频总结。`[标签: 多模态]`
15. **Quantization（量化）** - 降低模型参数精度来减小体积和加速推理。场景：手机端部署大模型。`[标签: 部署]`
16. **Reranker（重排序器）** - 在向量检索后对结果二次排序，提升相关性。场景：提升企业知识库问答准确率。`[标签: NLP]`
17. **Vector Database（向量数据库）** - 专存向量、支持语义相似度检索的数据库。场景：搭建百万级文档的知识库。`[标签: 基础设施]`
18. **Latency（首字延迟）** - 从发送请求到AI吐出第一个字的等待时间。场景：评估客服机器人是否够快。`[标签: 部署]`
19. **Throughput（吞吐量）** - AI系统单位时间内能处理的请求数量。场景：规划服务器容量。`[标签: 部署]`
20. **Alignment（对齐）** - 让AI的行为符合人类价值观和意图。场景：防止AI生成有害内容。`[标签: 安全]`
21. **Guardrails（护栏）** - 给AI设边界规则，防止越界回答。场景：企业客服AI拒绝回答无关问题。`[标签: 安全]`
22. **Grounding（接地）** - 让AI回答基于具体数据源而非自身参数记忆。场景：财报分析AI必须引用真实财报数据。`[标签: NLP]`
23. **Benchmark（基准测试）** - 用标准化题库评测模型能力打分排名。场景：选择最适合的模型时对比跑分。`[标签: 评测]`
24. **Open vs Closed Model（开源vs闭源）** - 开源模型可免费下载部署，闭源只能调API。场景：评估自建还是买服务。`[标签: 基础]`
25. **Agentic Workflow（智能体工作流）** - 多个AI智能体分工协作完成复杂任务。场景：一个Agent搜资料、一个写报告、一个审校。`[标签: Agent]`

## 进阶概念池（高级，18个）

1. **SFT（监督微调）** - 用标注好的问答对训练模型。相关：大模型训练 → 选这个。`[标签: 训练]`
2. **Chain-of-Thought（思维链）** - 让AI把推理步骤一步步写出来，答案更准。相关：推理能力 → 选这个。`[标签: 推理]`
3. **KV Cache** - 缓存已计算的键值对加速推理。相关：推理优化 → 选这个。`[标签: 推理]`
4. **Distillation（蒸馏）** - 用大模型教小模型，让小模型接近大模型水平。相关：模型压缩 → 选这个。`[标签: 训练]`
5. **MCP（Model Context Protocol）** - 让AI标准连接外部工具和数据的标准协议。相关：AI Agent → 选这个。`[标签: Agent]`
6. **Function Calling** - 让大模型调用外部API或函数。相关：AI Agent → 选这个。`[标签: Agent]`
7. **Constitutional AI（宪法AI）** - 让AI用一套规则自我纠正，减少有害输出。相关：AI安全 → 选这个。`[标签: 安全]`
8. **Red Teaming（红队测试）** - 专门攻击AI系统找漏洞的测试方法。相关：AI安全 → 选这个。`[标签: 安全]`
9. **Mixture of Depths** - 让模型动态决定哪些层需要深度计算，其他层跳过省算力。相关：模型架构 → 选这个。`[标签: 架构]`
10. **Speculative Decoding（投机解码）** - 用小模型猜答案、大模型验证，加速推理。相关：推理加速 → 选这个。`[标签: 推理]`
11. **VLA（视觉-语言-动作模型）** - 同时理解图像、语言并输出物理动作指令的模型。相关：具身智能/机器人 → 选这个。`[标签: 多模态]`
12. **Test-time Compute（测试时计算）** - 模型在推理阶段动态分配更多算力来"想更久"，答案更准。相关：推理能力 → 选这个。`[标签: 推理]`
13. **Reasoning Model（推理模型）** - 如o1/o3系列，内置长思维链，擅长复杂数理逻辑。相关：推理能力 → 选这个。`[标签: 推理]`
14. **World Model（世界模型）** - AI内部建立的物理世界运行规律模拟，可预测行为后果。相关：具身智能/自动驾驶 → 选这个。`[标签: 多模态]`
15. **Multimodal RAG** - 不仅能检索文字，还能检索图片、表格、PDF扫描件。相关：RAG → 选这个。`[标签: 多模态]`
16. **AI Coding Agent（AI编程智能体）** - 能理解需求、写代码、跑测试、修Bug的全流程编程AI。相关：AI Agent → 选这个。`[标签: Agent]`
17. **GRPO（群组相对策略优化）** - 不需要人类标注，让模型自己跟自己比来学习。相关：训练方法 → 选这个。`[标签: 训练]`
18. **Inference-time Scaling（推理缩放定律）** - 推理时投入越多算力，模型表现越好，是训练缩放定律的推理侧对应。相关：推理能力 → 选这个。`[标签: 推理]`
