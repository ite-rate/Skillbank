# 16 页答辩/汇报 deck 版面配方（pptxgenjs，13.33×7.5 LAYOUT_WIDE）

Proven layout recipes from a 数据要素大赛 答辩 deck (安阳宾馆智慧消防项目). Reuse per slide type; adjust copy, keep geometry discipline (body 9.5-11pt, `fit:"shrink"` on dense boxes, footer bar with `NN / 16`).

## 通用骨架
- 内容页: `header(slide, tag, title, tagColor)` = 0.07×0.34 左侧色块 + 11pt 彩色 tag + 24pt 粗标题 (y 0.62)。不要标题下划线（AI 味标志）。
- 页脚: 深蓝条 y H-0.42 h 0.42，左 8pt 赛事/项目名，右页码。
- 卡片: RECTANGLE 白底 + 0.06" 左侧色条 + 细边 E2E6EA + 软阴影。圆角色块(chip)用 ROUNDED_RECTANGLE rectRadius=h/2，不要叠加直角 accent 条。

## 逐页配方
- **封面/致谢(深色 0F1B2D)**: 顶部+底部 0.09" 红色条呼应；封面三色小方块装饰(红/琥珀/青绿)；主标题 40pt，副标题 17pt 带「——」包裹，赛道琥珀色，日期+单位 11pt 灰；致谢 44pt 大字 + 16pt 副字。
- **一句话定位**: 白卡(红左条)内 21pt 粗体主张句 + 三个圆角 chip（利旧激活/算力赋能/保险兜底 式关键词）+ 斜体灰副语。
- **痛点三卡**: 3×3.94" 卡片，编号 01/02/03 大号彩色 + 标题 + 3 条 bullet + 底部虚线占位框；页底深蓝圆角条放 4 个背景数字（19层 | 23000㎡ | …）。
- **架构总览**: 4 条全宽横带（白底+左侧 2.35" 彩色标签块+右侧描述），自上而下排；左右两侧 0.62" 窄竖卡放「两翼」体系（逐字换行竖排）；页底 4 个关键数字 chip（130→32路 / 100TOPS / 5-10秒 / 19层）。
- **数据流核心页**: 4 节点横排（每个: 顶部 0.4" 色条标题 + 8.5pt 描述），节点间用两个小圆点模拟箭头；下方全宽回流带（浅绿底 11pt 粗体"回流闭环…"）；左下 4 行数据量表 + 右侧"增值路径"卡片；页底总结句引用框（红左条）。
- **优势大数字卡**: 卡片顶部 40pt 彩色数字 + 单位小字 + 标题 + bullets；数字用红/琥珀/青绿区分。
- **资质墙**: 左侧 bullets 列表（纯字符串，勿用嵌套富文本）+ 深蓝时间条（2012→2022→千家案例）；右侧 2×3 虚线占位框。
- **算力/组网**: 左侧 python 表格 2 列参数表（表头深蓝白字）+ 占位框；右侧 前后对比两个浅色块（红系=整治前，绿系=整治后）+ 两个小占位框；页底深蓝条一句话。
- **双案例**: 两个 6.04" 大卡，顶部色带 + 右上角标签 chip（已落地运行=绿 / 已部署试用=橙）；6 行 数据行（9pt 灰标签 + 9.5pt 粗值）；底部 3 个 0.42" 照片占位框；页底"可复制性"总结条。
- **演示页**: 4 步流程卡（圆形编号 + 标题 + 描述 + 虚线截图占位）+ 下方大面积深蓝视频占位框（▶ 演示视频占位 + 流程说明 + 琥珀色待办提示）。
- **成效四卡**: 4×2.95" 卡，30pt 大数字 + 3 条展开；页底浅灰虚线框"运营数据持续积累中（待补充）"。
- **商业模式**: 上排 传统灰卡 vs 本项目蓝卡；中排 4 个模块化定价 chip；下排 3 档价格条（红粗体金额）+ 对比句；页底深蓝盈利结构条（首年80% → 第三年50%+）。
- **推广**: 上排 3 路径卡；中排 3 步时间线（步骤 chip + 标题 + 状态色字，步间小圆点箭头）；右下 意向协议虚线框。
- **市场空间**: 顶部 3 个大数字卡（28pt 数字 + 说明）；场景链 chip+箭头；4 行说明表；页底深蓝政策条（可选项→必选项）。
- **价值总结**: 3 列卡 + 页底青绿色总结句引用框。
